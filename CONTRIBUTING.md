# About this repository

This repository is the documentation and examples for the
[tiktok-scraper](https://apify.com/clearfetch/tiktok-scraper) Actor. The Actor's source is not published here.

`sample-output.json` is a real row from a real run, a video from TikTok's own @tiktok account, with media links
shortened.

Found a bug, or need a field that is not in the output? Open an issue here, or use the Issues tab on the Actor
itself. Both reach me.
